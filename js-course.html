⚡ دوره آموزش JavaScript

با JavaScript سایت خود را تعاملی کن.

درس 1: JavaScript چیست؟

JavaScript یک زبان برنامه‌نویسی است که باعث تعامل سایت با کاربر می‌شود.

console.log("سلام دنیا");
📝 تمرین: عبارت «Hello World» را در console چاپ کن.

درس 2: متغیرها

var name = "Ali"; var age = 20;

متغیر برای ذخیره اطلاعات استفاده می‌شود.

📝 تمرین: یک متغیر برای نام و یک متغیر برای سن بساز.

درس 3: alert

alert("سلام!");

alert یک پیام به کاربر نشان می‌دهد.

📝 تمرین: یک پیام خوش‌آمدگویی با alert نمایش بده.

درس 4: شرط‌ها

var age = 18; if (age >= 18) { console.log("بزرگسال"); } else { console.log("نابالغ"); }
📝 تمرین: بررسی کن یک عدد مثبت است یا منفی.

درس 5: توابع

function hello() { alert("سلام!"); } hello();

تابع مجموعه‌ای از دستورات است که می‌توانیم چند بار اجرا کنیم.

📝 تمرین: تابعی بساز که نام کاربر را نمایش دهد.

درس 6: رویداد کلیک

<button onclick="hello()"> کلیک کن </button> <script> function hello() { alert("سلام!"); } </script>
📝 تمرین: با کلیک روی دکمه یک پیام نمایش بده.

درس 7: تغییر HTML

document.getElementById("title") .innerHTML = "سلام";

JavaScript می‌تواند محتوای HTML را تغییر دهد.

📝 تمرین: متن یک h1 را با JavaScript تغییر بده.

درس 8: حلقه‌ها

for (var i = 1; i <= 5; i++) { console.log(i); }

حلقه برای تکرار دستورات استفاده می‌شود.

📝 تمرین: اعداد 1 تا 10 را چاپ کن.

درس 9: آرایه‌ها

var languages = [ "HTML", "CSS", "JavaScript" ]; console.log(languages[0]);

آرایه برای نگهداری چند مقدار استفاده می‌شود.

📝 تمرین: آرایه‌ای شامل 5 زبان برنامه‌نویسی بساز.

درس 10: پروژه کوچک

حالا می‌توانیم یک شمارنده ساده بسازیم.

var count = 0; function add() { count++; document.getElementById("number") .innerHTML = count; }
🎉 تبریک! دوره JavaScript را تمام کردی.
📝 پروژه: یک شمارنده با دکمه‌های افزایش و کاهش بساز.
