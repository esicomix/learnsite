🎨 دوره آموزش CSS

در این دوره یاد می‌گیری چطور ظاهر سایت را زیبا کنی.

درس 1: CSS چیست؟

CSS برای طراحی ظاهر صفحات HTML استفاده می‌شود.

h1 { color: blue; }
📝 تمرین: رنگ یک h1 را آبی کن.

درس 2: رنگ‌ها

body { background: lightblue; } h1 { color: red; }

می‌توانی از نام رنگ، HEX و RGB استفاده کنی.

📝 تمرین: پس‌زمینه صفحه را سبز کن.

درس 3: فونت و متن

p { font-size: 20px; font-weight: bold; text-align: center; }
📝 تمرین: یک متن 25 پیکسلی و وسط‌چین بساز.

درس 4: پس‌زمینه

body { background-color: #eef6ff; } .box { background-image: url("image.jpg"); }
📝 تمرین: پس‌زمینه یک div را تغییر بده.

درس 5: فاصله‌ها

.box { margin: 20px; padding: 15px; }

margin فاصله بیرونی و padding فاصله داخلی است.

📝 تمرین: برای یک کارت margin و padding قرار بده.

درس 6: Border

.box { border: 2px solid black; border-radius: 10px; }
📝 تمرین: یک کارت با گوشه‌های گرد بساز.

درس 7: کلاس‌ها

کلاس‌ها اجازه می‌دهند چند عنصر را با یک CSS کنترل کنیم.

.card { background: white; padding: 20px; }
📝 تمرین: سه کارت با کلاس card بساز.

درس 8: Flexbox

.container { display: flex; justify-content: center; gap: 20px; }

Flexbox برای چیدمان عناصر بسیار کاربردی است.

📝 تمرین: سه کارت را کنار هم قرار بده.

درس 9: Grid

.container { display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px; }
📝 تمرین: یک شبکه سه ستونه بساز.

درس 10: Responsive

Responsive یعنی سایت در موبایل، تبلت و کامپیوتر به شکل مناسب نمایش داده شود.

@media (max-width: 600px) { .container { grid-template-columns: 1fr; } }
🎉 تبریک! دوره CSS را تمام کردی.
📝 پروژه: یک صفحه کارت‌محور بساز که در موبایل یک ستونه شود.
