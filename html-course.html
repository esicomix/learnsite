🌐 دوره آموزش HTML

در این دوره HTML را از صفر یاد می‌گیری.

درس 1: HTML چیست؟

HTML زبان ساختار صفحات وب است.

با HTML مشخص می‌کنیم در صفحه چه چیزهایی وجود داشته باشد؛ مثل متن، عکس، لینک و فرم.

<h1>سلام دنیا</h1>
💡 HTML برای طراحی ظاهر نیست؛ ساختار صفحه را مشخص می‌کند.
📝 تمرین: یک عنوان با متن «سلام دنیا» بساز.

درس 2: اولین صفحه HTML

یک صفحه HTML معمولاً با ساختار زیر شروع می‌شود:

<!DOCTYPE html> <html> <head> <title>صفحه من</title> </head> <body> <h1>سلام دنیا</h1> </body> </html>

بخش body محتوایی را نگه می‌دارد که کاربر در صفحه می‌بیند.

📝 تمرین: یک فایل index.html بساز و کد بالا را داخل آن قرار بده.

درس 3: عنوان‌ها و متن‌ها

برای عنوان‌ها از h1 تا h6 استفاده می‌کنیم.

<h1>عنوان اصلی</h1> <h2>عنوان دوم</h2> <p>این یک پاراگراف است.</p>
📝 تمرین: یک h1، یک h2 و سه پاراگراف بساز.

درس 4: لینک‌ها

برای ساخت لینک از تگ a استفاده می‌کنیم.

<a href="https://example.com"> ورود به سایت </a>
📝 تمرین: یک لینک به Google بساز.

درس 5: تصاویر

برای نمایش تصویر از img استفاده می‌کنیم.

<img src="image.jpg" alt="تصویر من">

ویژگی alt برای توضیح تصویر استفاده می‌شود.

📝 تمرین: یک تصویر به صفحه خود اضافه کن.

درس 6: لیست‌ها

لیست بدون ترتیب با ul ساخته می‌شود.

<ul> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> </ul>
📝 تمرین: لیستی از 5 زبان برنامه‌نویسی بساز.

درس 7: دکمه‌ها

<button> کلیک کن </button>

button برای ساخت دکمه استفاده می‌شود.

📝 تمرین: سه دکمه با متن‌های مختلف بساز.

درس 8: جدول‌ها

<table> <tr> <th>نام</th> <th>سن</th> </tr> <tr> <td>علی</td> <td>20</td> </tr> </table>
📝 تمرین: یک جدول سه ستونه بساز.

درس 9: فرم‌ها

<form> <input type="text" placeholder="نام"> <input type="email" placeholder="ایمیل"> <button> ارسال </button> </form>
📝 تمرین: یک فرم ثبت‌نام بساز.

درس 10: ساختار حرفه‌ای صفحه

در HTML5 می‌توانیم از تگ‌های معنایی استفاده کنیم.

<header> <nav> منو </nav> </header> <main> <section> محتوای اصلی </section> </main> <footer> پاورقی </footer>
🎉 تبریک! دوره HTML را تمام کردی.
📝 پروژه: یک صفحه شخصی با header، main و footer بساز.
